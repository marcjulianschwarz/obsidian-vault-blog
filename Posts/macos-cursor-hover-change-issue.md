I often encounter the problem that something steals my macOS cursor focus, and from that moment on, the cursor icon no longer changes on hover (pointer, finger, hand, arrows, etc.).

Today I learned that moving your mouse violently (a macOS feature that briefly increases the cursor size so you can find it on a big screen), will temporarily fix the problem until it comes back at some random point in time. I don't like that we have to rely on some weird mouse-movement hack instead of Apple fixing this, but hey, you now know how to fix it in that moment.
