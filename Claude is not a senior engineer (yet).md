# Claude is not a senior engineer (yet)

URL: https://www.approachwithalacrity.com/claude-ne/

An assessment of Claude 4.5's real-world coding performance, showing it can assemble well-designed blocks and automate tasks (e.g., a Playwright/Sentry debugging loop and an AWS ECS migration) but still falters at creating novel, safe solutions (as in a problematic React refactor), arguing that senior engineers remain indispensable and AGI won't replace them soon.
